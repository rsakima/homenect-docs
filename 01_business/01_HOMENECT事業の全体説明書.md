## HOMENECTとは

HOMENECTは、家のことで困っているお客様と、地域で仕事をする協力業者をつなぐ仕組みです。最初はエアコンクリーニングに集中し、予約・施工・記録・再注文・応援を一つにつなぎます。

## なぜ必要なのか

- お客様は「どこに頼めばよいか分からない」「料金や空きが分かりにくい」という不安がある。
- 個人事業者や小さな施工会社は、集客・予約管理・リピート・繁忙時の人手不足を一人で抱えやすい。
- HOMENECTは、双方の困りごとをつなぎ、地域全体で仕事を回しやすくする。

## 最初に提供するサービス

| 項目 | 正式方針 |
| --- | --- |
| 主力 | エアコンクリーニング |
| 開始地域 | 沖縄 |
| 顧客の入口 | Webを基本。LINEは補助 |
| 協力業者の業務画面 | Web / ホーム画面から使えるWeb版 |
| 決済 | MVPは現金を協力業者が直接受領 |
| 横展開 | 沖縄で実証後、他の住まいサービスへ |

## 三者のメリット

| 対象 | 主なメリット |
| --- | --- |
| お客様 | かんたん予約、料金・空き確認、施工履歴、再予約、応援体制 |
| 協力業者 | 新しい仕事、予約整理、リピート、忙しい時の応援、独立性維持 |
| HOMENECT運営 | 顧客獲得、品質管理、地域ごとの供給調整、全国展開の基盤 |

## 助け合いの仕組み

- 担当エリアは独占ではなく、HOMENECTから来た案件を優先的に案内する順番です。
- 忙しい・休み・難しい作業などの場合は、他の協力業者へ応援を依頼できます。
- 応援で別業者が施工しても、それだけで次回の優先担当は変えません。

## 案件価格保護・応援施工制度

協力業者によって通常料金が違っていても、HOMENECTはその価格を無理に統一しません。各協力業者が独立して自分の通常販売価格を決めます。

一方、A社で予約確定した案件をB社が応援する場合は、**業者変更だけを理由としてお客様の確定料金を原則変更しません。** B社には、お客様向け価格とは別の応援受託条件を提示します。

完全紹介としてB社との新しい契約へ切り替える場合は、B社の料金・条件をお客様へ事前提示し、お客様が承認した後に確定します。追加作業も内容と追加金額を施工前に承認してもらいます。

赤字・低採算になる応援案件は自動成立させず、別の応援先、差額負担、例外補填、新料金の再承認等へ分岐します。

協力業者同士で最低価格・標準価格・値上げ時期等を相談して共同決定する運用は行いません。

## 顧客の引き抜きを防ぐ考え方

- 協力業者が自力で獲得した顧客と、HOMENECTが獲得した顧客を分けて記録します。
- HOMENECTで得た顧客情報を使って、HOMENECTを外した直接取引へ不正に誘導することは防ぎます。
- 一方で、お客様自身が施工者を変更する自由は守ります。

## システムの基本

- お客様はWebから料金・空き・予約を確認。
- 協力業者は案件を受ける/断る、施工報告、応援依頼をWebで行う。
- LINEは問い合わせや重要通知など必要な場面で使い、売上につながらない有料送信を増やさない。
- 応援施工・完全紹介・追加作業・採算判定を別状態として記録する。

## 沖縄から全国へ

1. サービスとシステムを完成。
2. 内部テスト。
3. 沖縄の一部地域でお試し運用。
4. 品質・利益・供給・応援体制を確認。
5. 沖縄全体へ拡大。
6. 他県1地域で再現。
7. 全国展開。

## 運営の基本

通常案件はシステムで自動処理し、未割当、事故、キャンセル、応援、クレーム等の例外だけ人が確認する運営を目指します。

## 毎朝

- 今日の予約。
- まだ担当が決まっていない案件。
- 協力業者の休み・欠勤。
- 応援依頼。
- 重大事故・未解決クレーム。

## 日中

- 新規予約。
- 日時変更・キャンセル。
- 問い合わせ。
- 応援依頼。
- 事故・施工中トラブル。

## 夕方

- 完了していない案件。
- 作業前後写真の不足。
- 作業時間・試運転結果。
- 現金受領記録。
- 翌日の未割当案件。

## 毎週

- 売上・案件数。
- 協力業者の稼働。
- 辞退率・応援回数。
- クレーム・再施工。
- 未精算・未解決案件。

## 毎月

- 1件あたりの利益。
- 広告費。
- LINE等の通信費。
- 再注文率。
- 協力業者数・空き。
- 次の地域へ広げてよいか。

## 誰が何を決めるか

| 内容 | 原則 |
| --- | --- |
| 通常の予約・割当 | システム / 設定済みルール |
| 返金・補償 | 運営責任者 |
| 重大事故 | 運営責任者へ即時連絡 |
| 協力業者停止 | 事実確認後に運営判断 |
| 料金変更 | 事業責任者が正式料金表を更新 |
| エリア変更 | 供給・実績を見て運営判断 |

## 協力業者が辞めるとき

1. 今後の予約を確認。
2. 必要な案件を他の協力業者へ引き継ぐ。
3. お客様へ必要な案内。
4. 未完了・未精算を確認。
5. システムの顧客情報アクセスを停止。
6. 保管義務のある記録はHOMENECT側で保持。

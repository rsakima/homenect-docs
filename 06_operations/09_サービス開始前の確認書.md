# サービス開始前の確認書

版：v0.1（ひな形）  
更新日：2026-09-16

## 1. 事業
- [ ] 最初に販売するサービスが決まっている
- [ ] 本番料金が決まっている
- [ ] 協力業者への報酬・HOMENECT利用料が決まっている
- [ ] 誰と誰の契約になるか表示できる

## 2. 協力業者
- [ ] 実際に対応できる協力業者がいる
- [ ] 応援業者がいる
- [ ] 保険・資格等を確認した
- [ ] 担当エリア・空き設定を確認した
- [ ] 受ける・断るが自由にできる

## 3. お客様
- [ ] 料金・対応エリアが分かる
- [ ] Webで予約できる
- [ ] 予約確定前に料金・日時・支払・キャンセル条件を確認できる
- [ ] 問い合わせ先が分かる

## 4. 作業・品質
- [ ] 作業手順が決まっている
- [ ] 作業前後の写真ルールがある
- [ ] 試運転・完了確認ができる
- [ ] 再施工のルールがある

## 5. 事故・トラブル
- [ ] 水漏れ・破損時の手順がある
- [ ] クレーム対応手順がある
- [ ] 事故報告書がある
- [ ] 台風・災害時の対応がある

## 6. 個人情報
- [ ] お客様情報を必要以上に見せない
- [ ] 協力業者ごとの閲覧範囲を確認した
- [ ] 退会時にアクセスを止められる
- [ ] 個人情報の取り扱いを公開できる

## 7. システム
- [ ] 予約→施工→完了まで通してテストした
- [ ] 応援依頼をテストした
- [ ] LINEなしでも主要業務が動く
- [ ] バックアップと復元を確認した

## 8. 最終判断
- [ ] 開始する
- [ ] 修正してから開始する
- [ ] 開始を延期する

## 目的

施工者ごとの品質差を減らし、安全、接客、施工、記録をHOMENECTの基準にそろえることが目的です。

## 参加前確認

- 事業者情報。
- 対応地域。
- 対応機種・作業。
- 経験。
- 保険。
- 必要資格。
- 連絡方法。

## 基本研修

| 分野 | 内容 |
| --- | --- |
| HOMENECT | 仕組み、担当エリア、応援、顧客関係 |
| 接客 | 挨拶、説明、遅刻連絡、クレーム初動 |
| 安全 | 養生、電気、水、薬剤、作業停止判断 |
| 施工 | 標準手順、対応外作業 |
| 記録 | 前後写真、時刻、試運転、異常 |
| 個人情報 | 顧客情報の利用範囲、直接取引防止 |
| 事故 | 安全確認、記録、運営連絡 |

## テスト施工

実際または模擬のエアコンクリーニングで、次を確認します。

- 作業前確認。
- 養生。
- 安全な分解・洗浄。
- 復旧・試運転。
- 写真。
- お客様への説明。
- 完了登録。

## 合格基準

- 危険な手順がない。
- 必要な写真・記録がそろう。
- 対応外の判断ができる。
- 事故時の連絡方法を理解。
- お客様への説明が適切。
- 顧客情報のルールを理解。

重大な安全違反がある場合は他項目の点数にかかわらず合格にしません。

## 対応レベル

| レベル例 | 対応範囲 |
| --- | --- |
| 標準 | 通常壁掛け |
| 上位 | お掃除機能付き等 |
| 専門 | 特定機種・電気・水回り等、必要資格/技能がある作業 |
| 指導 | 新人の同行・指導が可能 |

正式な名称・条件は運用前に確定します。

## 再確認・停止

重大事故、再施工の増加、記録不足、ルール違反等がある場合は、事実確認のうえ研修、対応範囲縮小、案件停止等を行います。申告だけで自動処分せず、記録・説明を確認します。

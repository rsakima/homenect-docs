## 表示項目ひな形

| 項目 | 記載内容 |
| --- | --- |
| 販売/役務提供事業者 | ［正式会社名または実際の契約主体］ |
| 運営責任者 | ［氏名］ |
| 所在地 | ［住所］ |
| 電話番号等 | ［連絡先］ |
| 販売価格/役務対価 | 各サービスページ・予約画面に表示 |
| 追加料金 | 駐車料金・追加作業等がある場合表示 |
| 支払方法 | 現金等、実運用に合わせて記載 |
| 支払時期 | ［内容］ |
| 役務提供時期 | 予約日時 |
| 申込みの撤回・解除 | キャンセル規定に記載 |
| 返金・再施工 | 正式ルールへのリンク |

## 予約最終確認画面

予約確定ボタンの直前に、少なくとも次の内容を分かりやすく確認できるようにします。

- サービス内容。
- 数量・台数等。
- 料金・追加料金。
- 支払い方法・時期。
- 施工日時等。
- キャンセル・解除に関する条件。
- 実際の契約主体。

入力ミスを確認・修正できるようにします。

## 注意

HOMENECTが媒介のみを行うのか、施工サービスの契約主体になるのか等によって表示義務・内容が変わる可能性があります。正式な事業モデル確定後に専門家確認します。

# 集客・料金・売上の考え方

> **同期元:** `09_集客・料金・売上/08_集客・料金・売上の考え方.docx` / 2026-09-16 v1.1

## 集客の基本

「LINE友だち数」や「アクセス数」だけで成功を判断しません。実際に予約され、施工され、利益が残り、再注文につながるかまで確認します。

## 集客経路

| 経路 | 主な確認 |
| --- | --- |
| 検索・SEO | Web流入、予約率、1件獲得費 |
| 広告 | 広告費、クリック、予約、1件利益 |
| 協力業者の紹介 | 紹介件数、再注文、利用料 |
| お客様の紹介 | 紹介率、獲得費 |
| SNS | Webへの流入、予約 |
| LINE | 問い合わせ、予約後利用、送信費 |

## 料金

料金は競合だけで決めず、協力業者の報酬、広告費、通信費、事故対応、運営費等を含めて継続できる価格にします。正式料金は別紙で管理します。

協力業者ごとの通常販売価格は統一せず、各協力業者が独立して自主的に設定します。HOMENECTは表示項目・説明方法・追加料金の事前提示ルールを統一します。

## 協力業者への報酬

仕事を受ける合理性がある報酬にします。HOMENECTが獲得した新規案件、自力獲得、再注文、応援案件を同じ手数料で扱う必要はありません。

## HOMENECTの収益

一律20%を前提にはしません。獲得元、HOMENECTが提供した価値、案件ごとの利益を見て、固定利用料・案件利用料等を組み合わせて検証します。

## 案件価格保護・応援施工制度

### 応援施工

- お客様の確定済み料金を原則維持します。
- 応援業者への支払条件は、お客様向け通常価格と分離して管理します。
- HELPだけでは優先担当を変更しません。

### 完全紹介

- 新しい業者の料金・条件を事前提示します。
- お客様の承認後に新しい予約を確定します。

### 追加作業

- 内容と追加金額を施工前に提示します。
- お客様の承認後に施工します。

### 採算ガード

`案件の残り = お客様確定価格 - 応援業者への支払 - HOMENECT利用料 - その他変動費 + 例外補填`

- 残りが設定基準以上：成立可能。
- 基準未満：自動成立禁止。
- 赤字：自動成立禁止。
- 例外補填は事故・運営都合等の限定ケースで使い、原則0とします。

### 競争ルール

- 業者間で最低価格・標準価格・値上げ時期を相談して調整しません。
- 応援業者の通常販売価格を元業者へ常時公開しません。
- 案件ごとに必要な受託条件だけを提示します。

## 通信費

Web・メール・Web通知を基本に使い、LINEの課金対象送信は価値の高い場面へ限定します。未成約のお客様への課金LINE Pushは原則行いません。

## 再注文

初回獲得より再注文のほうが集客費を下げやすいため、施工履歴、前回と同じ予約、適切な時期の案内等で継続利用しやすくします。

## 毎月見る数字

- 予約件数。
- 施工完了件数。
- 1件あたり売上。
- 協力業者報酬。
- 顧客獲得費。
- 通信費。
- 1件あたり残る金額。
- 応援案件の平均残額。
- 赤字/低採算でブロックされた案件数。
- 再注文率。
- クレーム・再施工率。
- 協力業者の受諾率・空き状況。

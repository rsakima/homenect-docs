# HOMENECT 料金・報酬・収益シミュレーション v1.1

> **同期元:** `14_管理台帳・用紙/HOMENECT_料金・報酬・収益シミュレーション_v1.1.xlsx` / 2026-09-16

## 正式方針

料金・報酬は一律固定せず、各協力業者の通常価格、獲得元、案件価値、応援条件、実際の採算を分けて管理します。

## 1件モデル

基本式：

`1件の残り = お客様売上 - 協力業者報酬 - 広告費 - 通信費 - その他変動費`

## 獲得元別

協力業者自力獲得、紹介、自然検索/SEO、広告等を分けてCACと1件の残りを確認します。

## 月間モデル

`月間の残り = 月間売上 - 月間変動費 - 固定費`

## LINE等の通信費

- Web画面内・Email・Web通知を基本にする。
- LINE Pushは価値の高い場面へ限定する。
- 未成約のお客様への有料LINE Pushは原則0。
- 単価は公式料金改定に合わせてConfig更新する。

## 応援案件の採算

| 入力 | 説明 |
| --- | --- |
| お客様確定価格 | 予約確定時にロック |
| 応援業者への支払 | 案件提示時の受託条件 |
| HOMENECT利用料 | 案件区分ごとに設定 |
| その他変動費 | 通信費など |
| 例外補填 | 原則0。事故・運営都合等の限定ケース |
| 最低残額基準 | これ未満は自動成立禁止 |

計算式：

`応援時の残り = お客様確定価格 - 応援業者への支払 - HOMENECT利用料 - その他変動費 + 例外補填`

### 判定

- 残り >= 最低残額基準：成立可能。
- 0 <= 残り < 最低残額基準：低採算、自動成立禁止。
- 残り < 0：赤字、自動成立禁止。

## 完全紹介

新しい業者の価格との差額をお客様へ明示し、承認後に予約確定します。応援施工の採算計算とは分けて記録します。

## Pilotで実測する数字

- 予約完了率。
- 再注文率。
- Partner受諾率。
- 応援成功率。
- 再施工率。
- 重大事故。
- 1件の残り。
- 応援案件の残り。
- 赤字/低採算ブロック件数。
- 1件あたり通信費。

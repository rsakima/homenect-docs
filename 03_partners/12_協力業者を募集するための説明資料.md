## HOMENECTとは

HOMENECTは、地域で仕事をするエアコンクリーニング事業者とお客様をつなぎ、予約・施工・記録・再注文・応援を一つにつなぐ仕組みです。

## 参加するとできること

| メリット | 内容 |
| --- | --- |
| 新しい仕事 | 空いている日にHOMENECTの案件を受けられる |
| 応援 | 忙しい・休み・難しい作業を仲間に頼める |
| 予約整理 | 案件をWebでまとめて確認できる |
| 作業記録 | 写真・完了報告を残せる |
| 再注文 | 施工履歴を使って次回予約につなげやすい |
| 独立性 | 独立事業者のまま参加できる |

## 自分のお客様はどうなる？

自分で獲得したお客様を、HOMENECTが勝手に別の業者へ移すことはしません。応援で他の協力業者が施工しても、それだけで次回の優先担当は変更しません。

## エリアについて

担当エリアは独占権ではありません。HOMENECTから来た案件を、距離・空き・技能などを見ながら優先的に案内するための仕組みです。

## 仕事は断れる？

はい。案件ごとに内容・日時・場所・報酬条件を確認し、受けるか断るか選べます。受付できない日はOFFにできます。

## 困った時は？

- 忙しくて行けない。
- 体調不良・休み。
- 難しい機種。
- 水漏れ・事故。
- 技術相談。

このような場合は、HOMENECTから他の協力業者へ応援を依頼できます。

## 専用アプリは必要？

専用アプリは必須ではありません。Webを基本にし、よく使う協力業者はホーム画面から開きやすくできます。LINEは補助として使います。

## 参加までの流れ

1. 説明。
2. 申込み。
3. 事業者情報、保険、資格、対応内容の確認。
4. 研修・テスト施工。
5. 合格。
6. 案件受付開始。

## 料金・利用料

一律の手数料をこの資料では固定しません。HOMENECTが獲得した新規案件、協力業者が自力で獲得した案件、再注文、応援案件などの違いを考慮し、正式な料金・報酬表で案内します。

## 参加前に確認すること

- 対応できる地域。
- 対応できる機種・作業。
- 保険。
- 必要な資格。
- 連絡方法。
- 仕事を受けられる曜日・時間帯。
- 事故時の連絡方法。

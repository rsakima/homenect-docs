## ブランド名

正式ブランド名は **HOMENECT** です。地域名をブランド名へ固定せず、必要に応じて「沖縄発」等を説明に使います。

## ブランドの考え方

- 家・暮らし。
- 人と人をつなぐ。
- お客様と地域の事業者をつなぐ。
- 事業者同士を助け合いでつなぐ。
- 沖縄の実証を全国へつなぐ。

## 言葉

難しいシステム用語より、生活者・協力業者が理解できる言葉を使います。

例：
- Partner → 協力業者。
- Preferred Area → 優先担当エリア。
- HELP → 応援依頼。
- Pilot → お試し運用。
- Incident → 事故・トラブル。

## 色

| 用途 | 色の考え方 |
| --- | --- |
| 主色 | 深いネイビー。信頼・安心 |
| 副色 | ティール/青緑。清潔・つながり |
| 背景 | 白・薄い水色。見やすさ |
| 注意 | 赤・橙は警告等、必要な場所だけ |

## ロゴ

承認済みブランドボードを正とします。ロゴを変形・縦横比変更・読みにくい背景へ置くことを避けます。小さい表示ではシンボルのみを使用できます。

## 沖縄の扱い

HOMENECTは沖縄限定ブランドではありません。「沖縄発」「沖縄で実証」のように、事業の起点・実績として表現します。

## 協力業者での表記

「HOMENECT協力業者」「HOMENECT Partner」等の正式表記を決めて使用します。HOMENECT本部そのものと誤認させる表現は避けます。

## NG例

- ロゴ色を勝手に変更。
- HOMENECTの綴りを変更。
- 「最安」「絶対安心」等、根拠なく断定。
- 協力業者がHOMENECT本部を名乗る。
- 沖縄限定サービスと誤認させる表現を全国展開時も固定。

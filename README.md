# HOMENECT 正式資料

HOMENECTの事業・運営・施工・システム・契約に関する資料を管理する非公開リポジトリです。

## 管理ルール

- **GitHub**：文章の原稿、正式Decision、変更履歴、開発会社向け仕様を管理。
- **Google Drive**：人が読む完成版（Word / PDF / Excel / PowerPoint / 画像）を管理。
- **HOMENECT Web**：お客様向け公開情報を管理。
- 料金・報酬・対応エリア等の変動値は本文へ固定せず、管理表・Configで管理。
- 実顧客の氏名、住所、電話番号、施工写真、口座、身分証、秘密鍵等はGitHubへ保存しない。
- 契約・法務資料は本番公開・締結前に専門家確認を行う。

## 正式採用：案件価格保護・応援施工制度

[正式Decision全文](07_system/24_案件価格保護・応援施工制度_正式決定.md)

核心ルール：

- 各協力業者の通常販売価格は各社が独立して自主的に決定する。
- HELPでは業者変更のみを理由にお客様の確定料金を原則変更しない。
- 応援業者への受託条件はお客様価格と分離する。
- Referralでは新料金・条件を事前提示し、お客様承認後に確定する。
- 追加作業は施工前に内容・追加金額を承認してもらう。
- 赤字・低採算の応援案件は自動成立させない。
- HELPだけではpreferred Partnerを変更しない。
- 協力業者同士で最低価格・標準価格・値上げ時期等を共同決定しない。

## 案件価格保護・応援施工制度

### 案件ごとに保存する項目

| 項目 | 内容 |
| --- | --- |
| `handoff_type` | `none` / `help` / `referral` |
| `customer_price_locked` | 予約確定時のお客様料金 |
| `support_payout` | 応援業者への受託条件 |
| `platform_fee` | HOMENECT利用料 |
| `support_subsidy` | 事故等の例外的な差額補填。原則0 |
| `contract_party` | 施工契約主体 |
| `payee` | 料金受領者 |
| `service_partner` | 実施工業者 |
| `warranty_owner` | 保証・再施工窓口 |

### 採算判定

`案件の残り = customer_price_locked - support_payout - platform_fee - その他変動費 + support_subsidy`

- 基準以上：通常成立可能。
- 基準未満：自動成立禁止、例外確認。
- 赤字：自動成立禁止。

### 応援依頼書で確認する項目

- 元の担当業者。
- 実施工候補。
- 応援理由。
- お客様確定価格。
- 応援受託条件。
- HOMENECT利用料・変動費。
- 案件の残り。
- preferred partnerを維持するか。
- 完全紹介へ変更するか。

### 売上・支払い管理の追加項目

- `handoff_type`
- 応援報酬
- 例外補填
- 価格保護確認

## 重要ルール

- 協力業者の通常販売価格は各社が独立して決定する。
- 応援施工では、お客様の確定料金を原則維持する。
- 完全紹介では、新しい料金を事前提示し、お客様承認後に確定する。
- 追加作業は施工前承認。
- HELPだけではpreferred partnerを変更しない。
- 業者同士で最低価格・標準価格・値上げ時期等を相談して共同決定しない。
